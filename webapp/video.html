🦊 Завантажити відео

YouTube, Facebook, Instagram. Встав лінк — отримаєш файл, без реклами й «встановіть наш застосунок».

Це відео віддається лише тому, хто залогінений.

Дозволити качати від твого імені

Робиться один раз. Далі сторінка качає під тобою й нічого не питає.

  1. Постав розширення Get cookies.txt LOCALLY — для Chrome · для Firefox.
    Воно нічого нікуди не шле, лише зберігає файл на твій компʼютер.
  2. Відкрий facebook.com у тому ж браузері (ти там уже залогінений), тапни іконку розширення → Export.
  3. Перетягни збережений файл сюди:
    Перетягни cookies.txt або тапни, щоб обрати файл
    Не виходить із файлом — встав текст

Файл живе на сервері пів години, далі прибирається сам.

Якщо сторінка відкрита всередині Telegram і файл не зберігається — відкрий її у звичайному браузері («⋮ → Відкрити в браузері»): вбудований переглядач Telegram часто блокує завантаження.
